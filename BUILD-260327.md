# XrayR build with Xray Core 26.3.27

Built on Debian 13 amd64 from XrayR commit 974abc9, with `github.com/xtls/xray-core v1.260327.0`.

Includes NewV2board and Reality support, plus custom inbound/outbound/routing fragment loading. Custom fragments are loaded into the core configuration before panel services start.

The binary is provided as a compressed release archive; verify it with the accompanying SHA256 file.
